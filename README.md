# Shubham Bollu — Portfolio

Personal engineering portfolio website showcasing projects, industrial operations experience, research publications, certifications, and technical skills in **Robotics**, **Industry 4.0**, and **AI Infrastructure**.

---

## 🚀 Overview

- **Hero & Interactive 3D/Video**: Dynamic frame-scrubbed background sequence and 3D robot interaction.
- **Experience**: Operational engineering experience across **Amazon Web Services (AWS)**, **Tata Consultancy Services (TCS)**, and **Bosch Chassis Systems**, complete with interactive modal detail views and facility metrics.
- **Featured Project — ALLEGRI**: Edge AI-assisted reading of Gram stains & blood smears running YOLOv11 on Raspberry Pi 5 in partnership with Centre Hospitalier de Saint-Denis (Prize Winner).
- **Research & Innovation**: CFD analysis and thermal performance evaluation of solar-operated earthen pot cooling systems sponsored by **La Fondation Dassault Systèmes**, published in IJIRAE.
- **Skills & Verified Certifications**: Interactive certificate viewer for credentials across industrial automation, robotics, AI, MATLAB, and project engineering.

---

## 🛠️ Tech Stack

- **Frontend**: Pure HTML5, CSS3, modern Vanilla JavaScript (no external heavy frameworks, zero runtime dependencies)
- **Visuals**: HTML5 Canvas scroll-scrubbing animation, CSS Grid & Flexbox, responsive design for mobile, tablet, and desktop
- **Deployment**: Fully static, optimized for [Netlify](https://www.netlify.com/) with custom redirect rules and immutable asset caching headers (`netlify.toml`)
